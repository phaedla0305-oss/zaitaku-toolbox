# ChatGPT のメモリ用プロンプト②：チームのノウハウ・知識（2026-11-17）

> **2026-11-17追記：** ChatGPT側で永続メモリへの保存ができなかったため、同じ内容を `docs/chatgpt-project-prompt.md` の【プロジェクトの指示】に統合しました。今後はそちらを貼って使います（このファイルは記録として残します）。

Claude Code 側で運用しながら固まった決まりと知識を、ChatGPT 側でも同じ前提で使えるようにするためのものです。
ChatGPT のプロジェクト「在宅ワーク道具箱」のチャットに、枠を1つずつ貼り付けてください（量が多いため2回に分けています）。

> 古くなった前提の上書きも含みます（例：SNS投稿の広告表記は文末の「#PR」ではなく先頭の【PR】、提携案件はマイIPだけではなく3件）。
> プロジェクトの「指示」（docs/chatgpt-project-prompt.md の内容）が古いままでも、このメモリの内容を優先するよう書いています。
> 個人情報・ログイン情報・APIキーは含めていません。

## 1回目：サイト・案件・表記の決まり

```
次の内容を「在宅ワーク道具箱」のチームの前提としてメモリに保存してください。以前の指示と食い違う場合は、こちらを優先してください。保存したら、保存した項目の番号だけを返してください。

【在宅ワーク道具箱：前提とノウハウ（1/2）】
1. 名義はすべての媒体で「在宅ワーク道具箱」。サイト、X（@zaitaku_toolbox）、noteで同じ名前・同じアイコンを使う
2. 色は紺 #1F3A5F、オレンジ #F28C28（強調は1色だけ）、クリーム #FAF6EE。緑は補助色で、小さな文字には使わない。新しい画像はAI生成ではなくコードで描く
3. 提携案件は3件（A8.net経由）：マイIP（日本の固定IPのVPN）、GMOとくとくBBホームWi-Fi（工事不要のホームルーター）、GMOとくとくBB光（光回線）
4. サイト記事は6本：①カフェのフリーWi-Fi ②帰省先テレワークで社内ツールに入れない ③フリーランスの固定IPとメール例文 ④在宅ワークのホームルーター ⑤引っ越しの開通待ち ⑥セカイVPNとマイIPの違い
5. 広告表記：サイトは全ページの冒頭に「プロモーション（アフィリエイト広告）を含みます」を自動で表示。広告を紹介する章の冒頭に「※ここからは、当サイトが提携している広告（アフィリエイト）の紹介です。」を入れる。X投稿は本文の先頭に【PR】を付ける（文末の#PR・#広告は使わない）
6. 広告リンクは記事に生のURLを書かず、サイト内の中継ページ（go/案件名.html、検索除外）を通す。広告ボタンの直前に「こういう人に向いている」の条件を1文入れる
7. 料金・仕様は公式ページで確認した内容だけを書き、「○年○月○日時点、公式サイトより」と確認日を付ける。キャンペーン金額は時期で変わるので載せない。確認できない事実は書かないか、「確認できなかったこと」としてまとめる
8. 体験談は作らない。運営者が実際に測った・見たもの（自宅回線の速度測定3回、Androidのテザリング画面）だけを、日時・条件・限界つきで載せる
9. 記事の型：冒頭に「この記事でわかること」3行と結論 → 本文 → 選ばないほうがいい人・代わりの方法 → まとめ → よくある質問3問。関連記事へのリンクは本文中に1〜2本
10. 使わない表現：効果の断定、根拠のないNo.1・最安・100%、「誰でも稼げる」の類。リスティング広告向けの案は出さない（案件の規約で禁止）
```

## 2回目：運用・判断・安全の決まり

```
続けて、次の内容もメモリに保存してください。保存したら、保存した項目の番号だけを返してください。

【在宅ワーク道具箱：前提とノウハウ（2/2）】
11. X投稿は1日1件まで。1行目は読者の困りごと、記事にない効果を足さない、使っていない体験を書かない。リンクにはUTM（utm_source=x）を付ける
12. 自分で広告リンクを押して申し込む・成果を作ることはしない。動作確認でも広告リンクを繰り返し押さない
13. 合意事項：12/16の振り返りまで新しい施策は始めない。noteからサイト・広告へのリンクは12/16まで置かない。12月の記事本数（週2本／週4本）は運営者が11/30までに決める。自動企画は12/1まで休止
14. 予算：Claude APIは月33ドルまで（対象はClaude APIだけ）。ChatGPT APIとX APIの費用は別に記録する。新しい支出・契約・権限の追加は提案に留め、運営者が決める
15. 検索表示100・記事表示50・広告クリック20は「分析を始める目安」。到達しただけで改善効果や原因を断定しない。計測はすべてのデータを同じ期間でそろえて比べる（2026-11-17 ChatGPTの指摘で修正）
16. Search Consoleのインデックス登録リクエストは繰り返さない。次に状況を見るのは11/30
17. 外部の成功談（収益額・フォロワー数など）は確認できないので判断材料にしない。使える手法だけを取り出す
18. noteは公式の機能だけを使う（非公式のAPIや自動化はしない）。運営者の資格・勤務状況などの個人情報は、公開される場所（サイト、X、note、公開リポジトリ）に書かない
19. チームの分担：ChatGPTは案出し（発散）、Claude Codeは絞り込み・執筆・法令チェック・分析・実装（収束）、運営者は案件選定・事実確認・最終判断。ChatGPTへの相談は、最後に指定のJSON形式で答える
20. 新しい媒体や手法（楽天ROOM、noteへの広告掲載など）は、12/16の振り返りで検討候補にするかどうかから決める
```
