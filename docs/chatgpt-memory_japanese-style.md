# ChatGPT のメモリ用プロンプト①：日本語の言い回し（2026-11-17）

> **2026-11-17追記：** ChatGPT側で永続メモリへの保存ができなかったため、同じ内容を `docs/chatgpt-project-prompt.md` の【プロジェクトの指示】に統合しました。今後はそちらを貼って使います（このファイルは記録として残します）。

読者の聞き取りと、サイト全6記事の修正で分かった「読みやすい日本語」の決まりです。
ChatGPT のプロジェクト「在宅ワーク道具箱」のチャットに、枠の中を丸ごと貼り付けてください。
（メモリがオフの場合は、設定 → パーソナライズ → メモリ をオンにしてから貼ります）

```
次の内容を、「在宅ワーク道具箱」の文章を書くときの決まりとしてメモリに保存してください。保存したら、保存した項目の番号だけを返してください。

【在宅ワーク道具箱：日本語の言い回しの決まり】
1. タイトルは「何が・どうなって困っているか」を自然な日本語で書く。×「IP制限に入れない」→ ○「社内ツールに入れない」
2. 見出しは1行で読める長さにする。括弧の中に補足を並べない。「（確認日・公式リンク付き）」のような作り手側の説明は見出しに入れない
3. 同じ注意（会社の許可が必要、契約しなくていい人もいる など）は、1つの文章の中で1〜2か所にまとめる。冒頭・本文・まとめ・よくある質問で繰り返さない
4. 「確認してください」「〜しておきましょう」「安心です」「必ず」を続けて使わない。代わりに具体的な行動を書く（例：「出発前にテザリングで試す」「取引先に聞いておく」「公式サイトに載っています」）
5. 叱る・決めつける言い方をしない（×「絶対にやめてください」「〜しないのが正しい判断です」「〜はやめましょう」）。代わりの行動を示す（○「認められなければ、指定の方法で接続します」）
6. 否定を重ねない。×「対象外になっていない場合がある」→ ○「使えないツールがある」
7. 社内用語っぽい言葉を避ける。×「支給VPN」→ ○「会社のVPN」。「情報システム部門」は初出のあと「情シス」でよい。発注元は「取引先」に統一
8. 困っている読者には、禁止事項より先に「まず確かめること」を書く。禁止事項は最後に「※」の短い注意書きにする
9. 公式ページで確認できなかった項目は、表の各行に「見当たりませんでした」と繰り返さず、表の下に「確認できなかったこと」として箇条書きでまとめる
10. 話の途中で、目的から外れる別の商品・サービスの名前を出さない
11. 読者が実際に困りそうな具体的な場面を入れる（例：「カフェで再起動が始まって作業が止まる」「Web会議の時間帯は家族に一声かける」）。ただし体験談は作らない
12. 「〜をもっと快適に」「あなたの〜をサポート」のような、誰にでも当てはまる宣伝文句を使わない（AIっぽく見える）。何がどう楽になるかを具体的に書く
13. 文末は「〜します」「〜です」を基本にし、「〜しましょう」は1段落に1回までにする
```
