# 導線の見直し（Claude Code案、2026-11-16）

目的：読者がサイト・X・noteのどこから入っても、自分の状況に合うサイトの記事（A8の広告がある記事）にたどり着けるようにする。収益は今のところサイトのA8案件（回線・VPN）だけ。

## 1. 現状の導線
| 入口 | 行き先 | 状態 |
|---|---|---|
| 検索 → サイト記事 | 記事内の広告（go/経由、PR表記・計測あり）、関連記事 | 6記事。②⑤に検索流入が少し。広告クリックは0 |
| X（自動投稿 1日1件） | サイト記事（UTMつき） | 【PR】先頭。リンクなし投稿も3回に1回 |
| Xのプロフィール | サイトのトップ（短縮URL） | トップから記事へは一覧のみ |
| note（5記事） | なし（記事にサイトへのリンクなし） | 自己紹介にサイト名だけ（URLなし）。12/16までは広告誘導しない合意 |
| X → note | 運営者が11/16にnote記事を手動で告知 | 計測なし |
| サイト → note | なし | — |
| A8 | サイトのみ媒体登録 | noteは未登録 |

## 2. 見直し案（収益への近さ順）
| # | 案 | 内容 | 合意・規約との関係 | 判断 |
|---|---|---|---|---|
| 1 | サイト内の導線を先に整える | どの記事からも「回線を選ぶ」「VPN・固定IP」の案件記事へ1クリックで行けるよう、記事末の関連記事と冒頭の「この記事が向く人／向かない人」の案内を見直す | サイト内の変更のみ。合意に影響なし | 推奨（すぐ着手可、APIなし） |
| 2 | noteの記事からサイトの記事へ1本だけリンク | 「サブスク整理メモ」の通信費に触れる箇所から、サイト④（ホームルーターと光回線の契約前チェック）へ。広告リンクはnoteに置かない。リンクにUTM（utm_source=note）を付けて計測 | 12/16まで「広告誘導しない」合意と、14日間の検証の計測（サイト訪問は参考値）に関わる → **合意の見直しが必要** | 運営者とChatGPTの判断待ち |
| 3 | noteの自己紹介にサイトのURL | 自己紹介の「サイト『在宅ワーク道具箱』」にURLを添える（UTMつき） | 2と同じ | 2と一緒に判断 |
| 4 | Xのプロフィールのリンク先 | 短縮URLをやめ、サイトのトップにUTMつきで直接リンク。トップに「まずはここから」の案内を置く | サイト内の変更とXの設定（運営者の操作） | 検討（効果は小さい可能性） |
| 5 | noteにA8の広告 | noteをA8に媒体登録し、案件ごとにnote掲載の可否を確認してから | 12/16まで保留の合意。noteの記事テーマ（サブスク・家計）と今の案件（回線・VPN）が合いにくい | 12/16以降に検討 |

## 3. 測り方（導線を変える場合）
- noteからサイト：GA4の参照元 note.com、またはUTM（utm_source=note）
- Xのプロフィールから：UTM（utm_source=x&utm_medium=profile）
- 広告クリック：サイトの affiliate_click（記事別・案件別）。A8の発生・確定は管理画面かCSV
- 量が少ない間は、良し悪しを断定しない（12/16の振り返りの基準どおり）

## 4. 判断が必要なこと
1. 案1（サイト内の導線）に着手してよいか
2. 案2・3（noteからサイトへ1本リンク）のために、「12/16まで広告誘導しない」合意を見直すか
