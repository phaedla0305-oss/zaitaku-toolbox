## 4. 確認後の対応（Claude Code）
- 各案件の指定が「#PR」「PR」「広告」など【PR】と異なる文言・位置を求めていた場合だけ、`pr_first()` の付け方（文言・位置）を最小限で直す案を出す。指定がなければ変えない
- SNS掲載が不可の案件があれば、その案件の記事をX投稿の対象から外す案を出す（affteam/sns.py の対象選び）
- Xアカウントのサイト登録や広告掲載URLの提出が必要と分かった場合は、手順を運営者に案内する（登録・提出は運営者が行う）
- 確認結果は config.yaml の各案件の rules と docs/policy_2026-11-15.md 7章に、確認日つきで記録する
