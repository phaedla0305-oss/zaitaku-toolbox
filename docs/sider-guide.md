# Sider（Chromeの拡張機能）の使い方（2026-11-17 導入）

運営者のChromeに、AIのサイドバー拡張機能「Sider」を入れた。見ているページの要約、ページの内容についての質問、文章の書き直しなどを、ブラウザの横で頼める。
このファイルは「在宅ワーク道具箱」の作業でSiderをどこに使い、どこに使わないかの決まり。Claude Code・ChatGPTの両方がこれに合わせて指示を出す。

## 1. 収益改善への効果（見込み）
Siderで広告収益が直接増えることはない。効くのは、記事の質と作業の速さを通した間接的な部分だけ。

| 効く場面 | 何が良くなるか | 収益とのつながり |
|---|---|---|
| 公開中の記事を、別のAIの目で点検する | 読みやすさの決まりに外れた箇所を、公開後の画面で見つけやすくなる | 読みやすい記事は最後まで読まれやすく、広告ボタンの手前まで届きやすい（効果の大きさは未評価） |
| 案件の公式ページを読むとき | 料金・契約期間・解約条件の箇所を探す時間が減る | 料金の変更に早く気づければ、古い情報による信頼の低下を防げる |
| 検索結果ページを見るとき | 上位記事のタイトルの傾向を短時間で表にできる | 12月以降の記事の切り口選び（企画の精度）に使える |

- 効果は数字で約束しない。評価は既存の計測（検索表示・記事表示・広告クリック）で、ほかの施策と同じ期間で行う
- 今ある自動化（GitHub Actions：公開・SNS告知・効果測定）は置き換えない。Siderは運営者が手で使う補助

## 2. 使わない場面（安全のため）
- **ログイン後の管理画面では使わない**：A8、Search Console、Googleアナリティクス、X・noteの設定画面・編集画面、メール、銀行・カード。Siderは見ているページの内容を外部のAIに送るため、アカウント情報や個人情報が送られるおそれがある
- 運営者の個人情報（資格、勤務状況、住所、連絡先）を入力しない
- 有料プランを契約しない（必要になったら運営者が判断する。新しい支出の扱い）
- 広告リンクを押さない。Siderからの自動投稿・自動操作をしない
- Siderの答えをそのまま記事・投稿に使わない。事実は公式ページの原文で確かめ、文章はClaude Codeのチェック（`affteam check`）を通す

**最初に1回だけやる設定（約1分）**：Chromeの右上のパズルのマーク →「拡張機能を管理」→ Siderの「詳細」→「サイトへのアクセス」を **「クリックされた場合のみ」** にする。こうすると、A8などを開いたときにSiderが勝手にページを読まない。

## 3. Siderで行う作業
いまの合意（12/16まで新施策なし）の範囲で使えるものだけ。どの作業も、結果を Claude Code に貼れば、直すか記録するかを Claude Code が決める。

### S1. 公開記事の読みやすさ点検（随時。1記事5分）
1. Chromeでサイトの記事を開く（例：https://phaedla0305-oss.github.io/zaitaku-toolbox/articles/cafe-free-wifi-safety-vpn.html）
2. Siderのサイドバーを開き、下の文を貼って送る
3. 答えをそのまま Claude Code に貼る

```
このページの記事を、次の決まりに照らして点検してください。違反している箇所を最大5つ、本文をそのまま引用して挙げてください。直し方の案は不要です。違反がなければ「なし」とだけ答えてください。
決まり：見出しは1行で読める長さ／同じ注意を3か所以上で繰り返さない／「確認してください」「安心です」「必ず」を続けない／叱る・決めつける言い方をしない／否定を重ねない／禁止事項より先に「まず確かめること」／目的から外れる商品名を出さない／「あなたの〜をサポート」など誰にでも当てはまる宣伝文句を使わない
```
※AIの点検であり、読者の評価ではない（読者の評価は聞き取りで別に扱う）

### S2. 案件の公式ページの料金チェック（月1回、または料金変更に気づいたとき。1案件5分）
1. 案件の公式ページを開く（マイIP：https://www.interlink.or.jp/service/myip/ 、ホームWi-Fi：https://gmobb.jp/gmohomewifi/ 、GMO光：https://gmobb.jp/service/gmohikari/ ）
2. 下の文を貼って送る
3. 答えと、確認した日付を Claude Code に貼る。Claude Code が記事の表と比べ、違いがあれば公式の原文を確かめてから直す

```
このページから、月額料金・初期費用・事務手数料・契約期間・解約時の費用・端末代・速度制限の条件を抜き出してください。項目ごとに、ページ内の原文をそのまま引用してください。ページに書かれていない項目は「記載なし」と書いてください。推測で補わないでください。
```
※広告リンク（A8経由のページ）ではなく、公式サイトのURLを直接開く

### S3. 検索結果の傾向メモ（11/25〜30、12月の本数を決める材料づくり。1キーワード5分）
1. Googleで、Claude Code が指定したキーワードを検索する
2. 検索結果のページで下の文を貼って送る
3. 答えを Claude Code に貼る

```
この検索結果ページに表示されている上位の記事について、タイトル・サイト名・読者のどんな悩みに答えているか（10字程度）を表にしてください。ページに表示されていない情報は書かないでください。
```
※記事の中身までは開かない。数字（検索数など）は推測させない

## 4. 両AIの分担
| 担当 | Siderに関してすること |
|---|---|
| Claude Code | 作業（S1〜S3）を出す時期を決める。結果を受け取って記事の修正・記録・材料づくりをする。決まりの更新 |
| ChatGPT | S3の結果から、記事の切り口案を出す（発散）。Siderに貼る文の言い回しの改善案を出す |
| 運営者 | Siderの操作と結果の貼り付け。有料プランや新しい使い道の判断 |
