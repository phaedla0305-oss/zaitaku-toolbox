## 画像ができたら（運営者の操作）
1. ChatGPT の画像をダウンロードする（ファイル名はそのままでよい）
2. note の下書き（https://editor.note.com/notes/ne5f28bb2e087/edit/ ）を開き、タイトルの上の画像アイコンから「画像をアップロード」を選んで設定する。位置がずれたら、表示される切り抜き枠で調整する
3. 「下書き保存」を押す（公開はしない）
4. ChatGPT が返した alt_text と caption_for_article を Claude Code に貼る（記事の末尾に注記を入れるかどうかを一緒に決める）

- 画像の日本語が崩れていたら、ChatGPT に「文字なしで作り直して」と伝える
- 見出し画像の推奨サイズの出典：note ヘルプ「登録画像の推奨サイズ一覧」（1280×670px、各画像10MBまで）
