# 仕事用と趣味用が混ざったサブスクを、20分で棚卸しする契約整理メモ

動画、音楽、クラウドの保存容量、仕事で使うツール。
毎月少しずつ払っているものが増えてくると、「何にいくら払っているのか」「いつ更新されるのか」がすぐには答えられなくなります。

特に、仕事にも趣味にも使っているサービスは、どちらの支出として考えるかがあいまいになりがちです。

この記事では、継続して払っている契約を1枚の表にまとめて、見直すときの土台を作る方法を紹介します。
筆者が自分の契約で試したときは、8件で約20分でした。

## この記事でできること
- 継続して払っている契約を、漏れなく書き出す
- 仕事用・趣味用・両方に分けて、月額と年額の合計を把握する
- 次の更新日と、解約・変更の手順を確認しておく

※ この表は「見直す点があるか」を確認するためのものです。解約や節約の効果を約束するものではありません。
※ 仕事用に分けたものが経費になるかどうかは、この記事では扱いません。税務署や税理士に確認してください。

## 用意するもの
- Excel、Googleスプレッドシート、またはスマホのメモアプリ
- クレジットカードの明細（直近1〜2か月分）
- スマホ料金の明細
- スマホの定期購入の一覧

## 棚卸し表の項目
| 項目 | 書くこと |
|---|---|
| サービス名 | 継続して払っているもの |
| 用途 | 仕事／趣味／両方（迷ったら「両方」） |
| 支払い方法 | カード、キャリア決済、口座振替、アプリ内課金など（番号は書かない） |
| 周期 | 月払い／年払い |
| 金額（月額・年額） | 年払いは年額を書き、月額は年額÷12の目安 |
| 次の更新日・請求日 | 月払いは「毎月◯日」、年払いは日付 |
| 解約・変更の手順を確認した | 済／未 |
| 最後に確認した日 | 表を更新した日 |
| メモ | 無料期間の終了日、家族の利用、手続きの場所など |

## 手順

### 1. 書き出す（約10分）
次の順に見ていくと、漏れが少なくなります。
1. スマホの定期購入の一覧（iPhoneは「設定」から自分の名前→「サブスクリプション」、Androidは「Playストア」のアカウントメニュー→「お支払いと定期購入」→「定期購入」。画面の名前は端末やバージョンによって異なることがあります）
2. クレジットカードの明細：毎月同じ名前で請求されているもの
3. スマホ料金の明細：携帯料金と一緒に払っているもの
4. その他：ネット回線、クラウドの保存容量、ソフト、会員制のサービスなど

### 2. 用途を分ける（約3分）
「仕事」「趣味」「両方」のどれかを書きます。ぱっと見で決めて大丈夫です。迷ったものは「両方」にしておきます。

### 3. 支払い方法・周期・金額を書く（約5分）
明細を見ながら埋めます。最後に月額と年額の合計を出すと、固定費の全体がつかめます（ExcelやスプレッドシートならSUM関数で計算できます）。

### 4. 更新日と、解約・変更の手順を確かめる
次の更新日を書いて、近い順に並べます。
解約や変更の手順は、実際の画面を開いて場所を確かめたら「済」にします。サービスによっては手順が分かりにくいこともあるので、すぐに見つからなければ「未」のままにして、公式のヘルプを後で確認します。
※ 画面を確かめるときに、解約ボタンは押さないでください。

### 5. 見直す日を決める
月1回、または年払いの更新の1か月前など、見直す日をカレンダーに入れておきます。

## 表ができたら確かめたいこと
- 同じような役割のサービスを、複数契約していないか
- 年払いの更新日が近いものはないか
- 「両方」に入れたものは、今の使い方に合ったプランになっているか

続けるか、プランを変えるか、やめるかは、使い方や家族の事情によって変わります。表は、その判断をするための材料として使ってください。

## まとめ
- 継続して払っている契約を1枚の表にまとめると、固定費の全体と更新日が見えるようになる
- 仕事用・趣味用・両方に分けておくと、見直すときに迷いにくい
- 解約・変更の手順は、困ったときではなく、表を作るときに確かめておく
