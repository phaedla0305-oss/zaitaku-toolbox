# 仕事にも趣味にも使うサブスク、どう分ける？契約と支払いの整理メモ

動画、音楽、クラウドの保存容量、仕事で使うツール。
毎月少しずつ払っているものが増えてくると、「何にいくら払っているのか」「いつ更新されるのか」がすぐには答えられなくなります。

特に、仕事にも趣味にも使っているサービスは、どちらの支出として考えるかがあいまいになりがちです。

この記事では、継続して払っている契約を1枚の表にまとめて、見直すときの土台を作る方法を紹介します。
（筆者が金額欄を加える前の試作版で自分の契約を整理したときは、8件で約20分でした。金額欄を加えた今の表では、時間を測っていません。）

## この記事でできること
- 確認できた契約を書き出し、まだ確認できていないものも「未確認」として整理する
- 用途ごとに分け、記入した契約の月換算額を合計する
- 次の更新日や請求日を、分かる範囲で一覧にする

※ この表は「見直す点があるか」を確認するためのものです。解約や節約の効果を約束するものではありません。
※ 仕事用に分けたものが経費になるかどうかは、この記事では扱いません。税務署や税理士に確認してください。

## 用意するもの
- Excel、Googleスプレッドシート、またはスマホのメモアプリ
- 支払いの記録：クレジットカードの明細、スマホ料金の明細
- 契約の記録：スマホの定期購入の一覧、各サービスの契約一覧（会員ページ）、更新のお知らせメール

カードの明細は直近1〜2か月分だけだと、年払いの契約を見落とすことがあります。年払いは、契約一覧や更新のお知らせメールでも確かめてください。

## 各項目の書き方
| 項目 | 書くこと |
|---|---|
| サービス名 | 継続して払っているもの |
| 用途 | 仕事／趣味／両方／生活／未分類（無理に当てはめず、迷ったら「両方」か「未分類」） |
| 支払い方法 | カード、キャリア決済、口座振替、アプリ内課金など（番号は書かない） |
| 周期 | 月払い／年払い／その他・不明 |
| 実際の支払額 | 1回に払う金額（年払いなら年額） |
| 月換算額 | 月払いはそのまま、年払いは年額÷12。予算をつかむための目安で、実際に毎月引き落とされる金額とは違う |
| 次の更新日・請求日 | 分かる範囲で。契約の更新日と請求日が違う場合は両方書く。分からなければ「未確認」 |
| 変更・解約の期限 | 更新前に手続きが必要な期限があれば。分からなければ空欄 |
| メモ | 無料期間の終了日、家族の利用、手続きの場所など |

## 手順

### 1. 書き出す
次の順に見ていくと、見落としを減らせます。
1. スマホの定期購入の一覧（iPhoneは「設定」から自分の名前→「サブスクリプション」、Androidは「Playストア」のアカウントメニュー→「お支払いと定期購入」→「定期購入」。画面の名前は端末やバージョンによって異なることがあります）
2. クレジットカードの明細：毎月同じ名前で請求されているもの
3. スマホ料金の明細：携帯料金と一緒に払っているもの
4. 契約一覧や更新のお知らせメール：年払いのもの、ネット回線、クラウドの保存容量、ソフト、会員制のサービスなど

定期購入の一覧とカードの明細の両方に同じ契約が出てくることがあります。1つの契約は1行にまとめて、重ねて書かないようにしてください。

### 2. 用途を分ける
「仕事」「趣味」「両方」「生活」「未分類」のどれかを書きます。ぱっと見で決めて大丈夫です。

### 3. 支払い方法・周期・金額を書く
明細を見ながら埋めます。合計するのは「月換算額」の列だけにしてください。実際の支払額（年額）と月換算額を両方足すと、同じ契約を二重に数えてしまいます。

### 4. 更新日・請求日を書く
分かる範囲で書いて、近い順に並べます。分からないものは「未確認」のまま進めて構いません。

### 5.（任意）変更・解約の手順を確かめる
ここまでで契約と金額が整理できれば、表は完成です。
余裕があれば、変更・解約の手順がどこにあるかを、各サービスの公式ヘルプなどで確かめておきます。画面を確かめるときに、変更や解約を確定する操作はしないでください。

## 表ができたら
金額を入れたら、月換算額と実際の支払い時期を分けて眺めてみましょう。今の使い方と合っているか、家族と共有しているか、更新前に確かめたい条件はあるか。すぐに変更を決めず、気になる点をメモしておくだけでも、次に確認することを整理できます。

月1回、または年払いの更新の1か月前など、表を見直す日をカレンダーに入れておくと続けやすくなります。

## まとめ
- 確認できた契約を1枚の表にまとめると、記入した範囲の継続的な支出と更新日が見えるようになる
- 合計は月換算額で出し、実際の支払額と二重に足さない
- 分からない欄は「未確認」のままでよい。まず契約と金額を整理するところまでを目標にする
