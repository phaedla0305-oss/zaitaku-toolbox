# サブスク・継続契約の棚卸し表（試作版 v0.2）

v0.2（2026-11-16）：運営者の試用（約20分・8件）を受けて、金額の欄を追加し、「解約・変更の確認先」を「手順を確認したか」に変更。

## 試すときの注意
- 記入したものは手元だけに置き、共有しない。**アカウントID・カード番号・ログイン情報・私的な利用履歴**は書かない
- 書きたくない欄は空欄でよい

## 棚卸し表
| # | サービス名 | 用途（仕事／趣味／両方） | 支払い方法（カード・キャリア・口座・アプリ内課金など。番号は書かない） | 周期（月・年） | 金額（月額） | 金額（年額） | 次の更新日・請求日 | 解約・変更の手順を確認した（済／未） | 最後に確認した日 | メモ（確認先、無料期間の終了日、家族の利用など） |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | |
| 合計 | | | | | （月額の合計） | （年額の合計） | | | | |

- 年払いのものは年額を書き、月額の欄には年額÷12の目安を書く
- 合計は、Excel・スプレッドシートなら SUM 関数で出せる

## 手順
1. 継続して払っているものを書き出す（スマホの定期購入一覧、カード明細、携帯料金の明細を見ながら）
2. 用途を「仕事」「趣味」「両方」に分ける（迷ったら「両方」）
3. 支払い方法・周期・金額を書く
4. 次の更新日を書き、近い順に並べる
5. 解約・変更の手順を、実際の画面で確かめたら「済」にする（解約ボタンは押さない）
6. 見直す日を決めてカレンダーに入れる（例：月1回、年払いの更新1か月前）

※ 仕事用に分けたものが経費になるかどうかは、この表では判断しない（税務署・税理士に確認）
※ この表は見直す点があるかを確認するためのもので、解約や節約の効果を約束するものではない
