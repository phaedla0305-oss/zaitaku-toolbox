# サブスク・継続契約の棚卸し表（試作版 v0.1）

運営者が手持ちの契約で試すためのひな形です。**記事にする前の試し書き用**で、まだ公開しません。

## 試すときの注意
- 記入したものは手元だけに置き、共有しない。共有する場合も、**アカウントID・カード番号・ログイン情報・私的な利用履歴**は書かない
- 金額やサービス名を書きたくない欄は空欄でよい
- 記入しながら「書きにくい欄」「いらない欄」「足りない欄」をメモする（下の振り返り欄）

## 仕事用と趣味用を分けて管理する手順（試作）
1. 上の表に、思いつく継続契約をすべて書き出す（カードやキャリアの明細、アプリのサブスク一覧を見ながら）
2. 用途の列に「仕事」「趣味」「両方」のどれかを書く。迷うものは「両方」にしておく
3. 次の更新日・請求日を書き、近い順に並べる
4. 「解約・変更の確認先」を、実際にその画面を開いて確かめてから書く
5. 見直す日を決めて、カレンダーに入れる（例：月1回、年払いの更新1か月前）

※ 仕事用に分けたものが経費になるかどうかは、この表では判断しない（税務署・税理士に確認）
