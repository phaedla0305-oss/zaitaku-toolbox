# Maxプランへの切り替えと、チームの自走化の案（2026-11-26）

## 1. 事実（2026-11-26、Claude Code が claude.ai の請求画面を閲覧）
- 運営者が Claude のプランを **Max**（Proの5倍の使用量）に切り替えた。請求 2026/11/26 **107.18ドル**（支払い済み）。次の自動更新は 2026/12/26
- 12/26以降の毎月の請求額は未確認（11/26の額はプランの切り替えに伴う額の可能性がある。推測しない）

## 2. Maxで変わること・変わらないこと
| 対象 | 変わるか | 理由 |
|---|---|---|
| Claude Code（このデスクトップアプリでの作業） | **変わる**：使える量が増える。長い作業や並行作業がしやすい | 定額プランの範囲で動くため |
| 自動の企画・制作（GitHub Actions の `affteam`） | 変わらない | Claude API（従量課金・月33ドルの上限）で動いている。定額プランとは別 |
| GitHub の `@claude`（claude.yml） | 変えられる（**要承認**） | 今は API キー（従量課金）。Max の利用枠で動かす設定（`claude setup-token` で発行したトークンを GitHub の秘密情報に登録）にすると、API の費用がかからない。ただし Max の利用枠をこのアプリでの作業と共有する |

- **今すぐ実施したこと**：なし。Max で直接よくなるのは Claude Code での作業量で、設定の変更は不要。claude.yml の切り替えは、秘密情報（トークン）の登録と権限の扱いが変わるため、運営者の承認後に行う

## 4. チームの自走化（ChatGPT・GitHubとの連携）
参考にしたX投稿（2026-11-20、Claude Code Digest）は、SandboxAQ の「Switch AI」というオープンソースの基盤の新機能「Switch Buddy」（複数のAIを同じ部屋で動かし、コピペでの引き継ぎをなくす）の紹介。**この外部のソフトは入れない**（内容と安全性を確かめていない。入れるとリポジトリやAPIキーにアクセスさせることになる）。同じ狙いを、今の仕組み（GitHub・Actions・OpenAI API）で作る案：

| 段階 | 内容 | 費用 | 必要な承認 |
|---|---|---|---|
| 0 | 稼働の観察画面のサンプル（Claude の Artifact、実際の記録を再生） | 0 | ― 済み |
| 1 | **ChatGPT との共有を自動に**：共有プロンプトが main に入ると、Actions が OpenAI API でChatGPT に送り、回答を Issue #39 と reports/chatgpt/ に残す。運営者のコピペをなくす | OpenAI API（1回 入力約3千・出力約2.6千トークン） | **実施済み（11/26、PR #38）** |
| 2 | **Claude Code が ChatGPT の回答を受けて動く**：回答を残したあと Issue #39 に `@claude` で照合を依頼し、GitHub上の Claude Code が採用分だけのPRを作る。Maxの利用枠で動く | Max の範囲（API費用なし） | **実施済み（11/26、PR #40）**。運営者がトークン登録（CLAUDE_CODE_OAUTH_TOKEN）とClaude GitHub Appの導入（zaitaku-toolboxのみ）を実施。読むだけの試しで動作を確認（約9秒）。リポジトリ変数 AUTO_CLAUDE_REVIEW=true で自動依頼をオン |
| 3 | **観察画面をライブに**：Actions が稼働の記録（JSON）を出し、GitHub Pages の非公開ページ（検索除外）で再生する。Artifact は外部のデータを読めないため、ライブ版は GitHub Pages に置く | 0 | 運営者の承認 |

- 守ること：公開（PRのマージ）・支出・権限の追加は、今までどおり運営者の判断。自走化しても、確認待ちのPRは自動でマージしない（今の自動マージは、チェックで指摘がない記事だけ）
- 12/16までの合意（新施策の保留、週次編集デスクの凍結）との関係：段階1〜3は新しい自動処理にあたる。運営者が「今やる」と決めた場合は、合意の例外として記録する

## 5. 運営者の判断事項

3. 12月のAI枠をいくらにするか（Maxの毎月の額が分かってから）
