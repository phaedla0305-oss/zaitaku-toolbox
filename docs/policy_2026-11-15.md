## 2. ChatGPTが挙げた抜け（対応）
### 2-1. 予算の範囲
- **現在の自動停止の仕組みは、Claude API の推定額だけを集計している**（`affteam/apicost.py`：実行ログのトークン数×公開料金。ChatGPT API と X の投稿料金は集計していない。いずれも実際の請求額ではない）
- 月33ドルを「Claudeだけ」にするか、「ChatGPT・Xを含む共有費用全体」にするかは**運営者の判断が必要**
- クレジットの購入額と実際の利用額は分けて記録する（購入額＝支出の予定、利用額＝実際に使った分）

### 2-2. 確認待ちを積み上げない制作条件（提案。実装は運営者の承認後）
- 案：`needs-review`（人の確認待ち）のPRが2件以上残っているときは、次の定時企画を実行しない（`schedule-check` に条件を追加）
- 人の確認が必要な理由（`<!-- 要確認 -->`、体験談の表現、AIレビューの指摘）は、PRに残す

### 2-3. 未登録記事（①③）の扱い
- 次回確認日：**11/16（月）7:00の週次計測**、その次は **11/30**
- 技術的な不具合が見つからない限り、登録リクエストは繰り返さない（11/8・11/10・11/13の3回で止める）
- AIレビューも、記事が変わらないまま繰り返さない
