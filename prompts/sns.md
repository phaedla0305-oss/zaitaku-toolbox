# 条件
- X 投稿を5案。各120字以内（URLは後で付けるので書かない）
- 切り口をばらす: 共感 / 数字・チェックリスト / 失敗談 / 質問形 / ビフォーアフター
- すべての投稿に次のいずれかのタグを必ず入れる: {{tags}}
- 投稿は「【PR】＋読者の困りごと・場面」の順で始まる。【PR】は投稿時にプログラムが先頭へ付けるので、あなたは困りごと・場面から書き始める（文の頭にPR表記を重ねない。商品名やスペックから始めない）
- 【PR】があっても、投稿全体を読んで広告だと分かる書き方にする（記事の紹介であること、提携先の案内を含むことを隠さない）
- 記事に書いていない効果・数値を足さない。使っていないのに「使ってみた」と書かない
- 広告見出しを5案（全角30字以内）
- 誇大表現・効果の断定はしない
