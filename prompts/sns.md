# 条件
- X 投稿を5案。各120字以内（URLは後で付けるので書かない）
- 切り口をばらす: 共感 / チェックリスト / よくあるつまずき（一般化して書く） / 質問形 / 確かめる順番
- 書き手の実体験に読める書き出しにしない（×「〜して失敗」「〜で作業が止まった」「昨年〜」）。つまずきは「〜することがあります」と一般化する
- 項目数・商品仕様・用語は、いまの記事と同じにする。記事で数を確かめられないなら数字を入れない。「○選」「これだけでOK」のように、条件を省く言い方をしない
- 症状だけで原因や解決策を決めつけない（×「途切れるなら回線変更」「VPNがあれば解決」）。先に確かめることや利用条件を示す
- 言い回しは記事と同じ決まりに従う（「支給VPN」→「会社のVPN」、「IP制限に入れない」→「社内ツールに入れない」、「安心です」「〜しましょう」を続けない）
- すべての投稿に次のいずれかのタグを必ず入れる: {{tags}}
- 投稿は「【PR】＋読者の困りごと・場面」の順で始まる。【PR】は投稿時にプログラムが先頭へ付けるので、あなたは困りごと・場面から書き始める（文の頭にPR表記を重ねない。商品名やスペックから始めない）
- 【PR】があっても、投稿全体を読んで広告だと分かる書き方にする（記事の紹介であること、提携先の案内を含むことを隠さない）
- 記事に書いていない効果・数値を足さない。使っていないのに「使ってみた」と書かない
- 広告見出しを5案（全角30字以内）
- 誇大表現・効果の断定はしない
