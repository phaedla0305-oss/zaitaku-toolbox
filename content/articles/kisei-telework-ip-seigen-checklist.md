> **この記事でわかること**
> - 帰省先から社内ツールに入れるかは、まず会社のルールと会社のVPNで決まります
> - 出発前に、自宅以外の回線（スマホのテザリングなど）で接続を試しておくと、当日あわてずに済みます
> - 個人で固定IPサービスを契約するのは、会社が登録を認めた場合だけです

## 結論：まずは会社のルールとVPNを確認

年末年始に実家から働く予定があるなら、出発前に次の順で確認します。

1. **会社のルールを確認する**：働いてよい場所、使ってよい回線、私物の機器やサービスの扱いをテレワーク規程で確認し、分からない点は情シス（情報システム部門）に聞く
2. **会社のVPNを試す**：自宅の光回線以外（テザリングなど）でつながるかを、出発前に試す
3. **帰省先の回線を確認する**：実家のWi-Fiの状態、テザリングのデータ容量
4. **個人で固定IPサービスを契約するのは最後**：会社が「個人で契約した固定IPを登録する」と認めた場合だけ検討する

会社のIP制限を自己判断で回避する方法は、この記事では扱いません。

## 帰省先だとIPアドレスが変わる理由

IP制限とは、「登録済みのIPアドレスから来たアクセスだけを通す」仕組みです。社内ツールが見ているのは、PCそのものではなく、**インターネットに出ていくときの回線のIPアドレス（グローバルIPアドレス）**です。同じ会社PCでも、つなぐ回線が変われば、社内ツールから見えるIPアドレスも変わります。

```
【自宅】   会社PC → 自宅ルーター → 自宅の光回線 → インターネット → 社内ツール
                                   └ 社内ツールに見えるIP：自宅回線のIP

【実家】   会社PC → 実家ルーター → 実家の回線   → インターネット → 社内ツール
                                   └ 社内ツールに見えるIP：実家回線のIP（自宅とは別）

【テザリング】会社PC → スマホ → 携帯キャリアの回線 → インターネット → 社内ツール
                                   └ 社内ツールに見えるIP：キャリア側のIP（変わりやすく、ほかの利用者と共有されることもある）

【会社VPN】 会社PC → どの回線でも → 会社のVPN装置 → インターネット → 社内ツール
                                   └ 社内ツールに見えるIP：会社のIP（構成による）
```

| 回線 | 社内ツールから見えるIP | 注意点 |
|---|---|---|
| 自宅の光回線 | 自宅回線のIP | 固定IP契約でなければ、自宅回線のIPも変わることがある |
| 実家の回線 | 実家回線のIP | 自宅とは別のIP。会社に登録されていなければ入れない |
| スマホのテザリング | キャリア側のIP | 接続のたびに変わりやすい。共有されている場合もある |
| 会社のVPN経由 | 会社側のIP（構成による） | 回線を問わず同じ出口になる設計が多いが、会社の構成しだい |

テザリングでIPが共有される背景には、「キャリアグレードNAT（CGN）」という仕組みがあります。Ciscoの技術資料によると、CGNは[サービスプロバイダーが、複数の加入者で1つのグローバルIPアドレスを共有できるように配置するNAT](https://www.cisco.com/c/ja_jp/td/docs/rt/wanaggregationinternetedgert/asr1000aggregationservsrt/cg/024/nat-xe-3s-asr1k-book/nat-xe-3s-asr1k-book_chapter_010.html)です。どの方式が使われているかはキャリアやプランによって違いますが、スマホ回線のIPを「自分専用の固定IP」として会社に登録するのは難しいと考えておくのが安全です。

**自宅で入れている理由を確かめておきましょう。** 普段自宅から社内ツールに入れている理由は、おおむね次のどれかです。

- (A) 会社のVPNにつないでいるから
- (B) 自宅回線のIPが会社に登録されているから
- (C) そもそもIP制限がかかっていないから

(A)なら帰省先でもVPNにつなげば入れる可能性が高く、(C)なら回線の心配はほぼいりません。注意が必要なのは(B)のときと、どれに当たるか分からないときです。分からなければ、次のチェック①で情シスに聞きます。

## チェック①：会社のルールを確認し、情シスに聞く

社内のテレワーク規程や情報セキュリティ規程で、次の項目を探します。

- 自宅以外（実家・帰省先）での勤務が認められているか。事前申請は必要か
- 使ってよい回線（自宅回線のみか、テザリングや他人のWi-Fiも可か）
- 公衆Wi-Fi（ホテル・カフェなど）の利用可否
- 会社PCに自分でソフトを入れてよいか。私物のVPNなどのサービスを使ってよいか
- 休暇期間中の情シスの対応体制と、緊急時の連絡先

書かれていないことは情シスに確認します。**年末年始は情シスも休みに入るため、出発の1〜2週間前までに送る**のがおすすめです。

**確認メール例（【】を書き換えて使えます）**

```
件名：【年末年始】帰省先からのリモート勤務時の接続方法について確認のお願い

情報システム部 ご担当者様

お疲れさまです。【部署名】の【氏名】です。
年末年始に、帰省先（【都道府県】の実家）から以下の日程でリモート勤務を予定しています。

・勤務予定日：【12月○日】【1月○日】
・使用端末：会社支給PC（資産番号：【○○○】）
・想定している回線：実家の光回線のWi-Fi／スマートフォンのテザリング

普段は自宅から【ツール名・管理画面名】を利用していますが、
帰省先の回線から接続する場合について、以下を教えていただけますでしょうか。

1. 上記ツールにIPアドレス制限はかかっていますか
2. 会社のVPN（またはリモート接続）を使えば、帰省先の回線からでも接続できますか
3. 実家のWi-Fiやテザリングの利用は、社内ルール上問題ないでしょうか
4. VPN等で接続できない場合、個人で契約した固定IPを登録していただくことは可能ですか
   （不可であれば、その前提で準備します）
5. 年末年始の休業中に接続トラブルが起きた場合の連絡先を教えてください

出発前の【○月○日】までに、テザリングで接続テストをしておく予定です。
お忙しいところ恐れ入りますが、よろしくお願いいたします。
```

質問4の答えが「不可」なら、固定IPサービスを契約しても社内ツールには入れません。会社の回答はメールのまま保存しておきましょう。

## チェック②：会社のVPNを、自宅以外の回線で試す

会社のVPNがあるなら、**自宅のWi-Fiを切り、スマホのテザリングで会社PCをつないで**試します。自宅にいるうちに試せば、うまくいかなくても情シスが動いている平日に相談できます。

- [ ] 会社PCを自宅Wi-Fiから切断し、スマホのテザリングに接続する
- [ ] 会社のVPN（リモート接続ツール）を起動し、ログインできるか確認する
- [ ] VPN接続中に、帰省先で使う予定の社内ツール・管理画面に**1つずつ**ログインする
- [ ] Web会議・ファイルのアップロードなど、当日やる予定の作業を試す
- [ ] 多要素認証（スマホアプリ・SMSなど）がテザリング中のスマホでも使えるか確認する
- [ ] エラーが出たら、画面のスクリーンショットと時刻を記録し、情シスに相談する

**VPNにつながっていても、使えないツールがあります。** 実際に使うツールまで開いて確かめてください。

帰省先で再起動したら更新が始まった、パスワードの期限が切れた、ということもよくあります。PCのアップデートとパスワードの更新は、出発前に済ませておきましょう。

## チェック③：帰省先のネット回線を確認する

### テザリング

- **データ容量**：Web会議や大きなファイルのやり取りは容量を多く使います。契約プランの月間データ容量と、テザリングの利用条件（オプションの申込みが必要か、上限があるか）を確認しておきます
- **会社への登録には向かない**：テザリングのIPは変わりやすいため、社内ツールに入るときは会社のVPN経由にするのが基本です
- **スマホの電池**：テザリング中は電池の減りが早くなります。充電ケーブルを用意しておきます

![Galaxyのテザリング画面。Wi-Fiテザリング、Bluetoothテザリング、イーサネットテザリング、USBテザリングのスイッチが並んでいる](../images/galaxy/02-tethering.jpg)

<p class="shot">Androidスマホ（Galaxy）の「設定 → 接続 → テザリング」画面（2026年11月10日、当サイト運営者の端末で確認）</p>

テザリングの設定画面を開けるか、通信量の確認方法が分かるかを、出発前に試しておきましょう。Androidの画面を使った手順は、「[引っ越しで光回線の開通待ち、テレワークは？](moving-fiber-waiting-telework-internet.html)」の「Androidでテザリングと通信量を確認する手順」で紹介しています。

### 実家のWi-Fi

- ルーターの場所とWi-Fiのパスワード（ルーター本体のラベルなど）を、家族に事前に聞いておく
- 実家の回線が使えないときに備えて、テザリングを予備にしておく（会社のルールで認められている場合）
- 家族の動画視聴などと重なると、回線が混むこともあります。Web会議の時間帯は家族に一声かけておくのも手です

### ホテル・駅・カフェなどの公衆Wi-Fi

総務省は「[公衆Wi-Fi利用者向け 簡易マニュアル（令和7年2月版）](https://www.soumu.go.jp/main_sosiki/cybersecurity/wi-fi/)」で、「接続するアクセスポイントをよく確認しよう」など3つのポイントを示しています。IPAの資料「[公衆無線LAN利用に係る脅威と対策](https://www.ipa.go.jp/security/reports/technicalwatch/hjuojm0000005mkw-att/000051453.pdf)」でも、第三者に通信内容を盗み見られる（盗聴）などの懸念が整理されています。

業務で使うなら、次の順で判断します。

1. 会社の規程で公衆Wi-Fiの利用が認められているか（禁止なら使わない）
2. 認められていても、会社の指示どおりVPNにつないでから業務をする
3. 接続先のネットワーク名（SSID）が、施設の案内と一致しているか確かめる

<p class="next">カフェやホテルなど公衆Wi-Fiでの安全対策は「<a href="cafe-free-wifi-safety-vpn.html">カフェのフリーWi-Fiは危険？在宅ワーカーの安全対策とVPNの選び方</a>」で詳しく解説しています。</p>

## チェック④：固定IPサービスが必要か判断する

個人で契約する固定IPサービスは、そのサービスのVPNサーバーを経由することで、どの回線からでも同じIPアドレスでインターネットに出られるようにするものです（マイIPの公式サイトでも、利用場所のネットワーク構成によっては使えない場合があると案内されています）。ただし、**社内ツールに入れるかどうかは、会社がそのIPを登録するかどうかで決まります。** 契約しただけでは入れません。

### 必要になるのは、次の条件がそろうときだけ

- 情シスが「個人で契約した固定IPを登録してよい」と認めている
- 会社PCにVPNの設定をする（またはアプリを入れる）ことが認められている。または情シスが設定してくれる
- 入りたいツールの制限が、IPアドレスだけで判定されている
- 年末年始の休業前に、情シスが登録作業を終えられる

### 契約しなくていい人

- 会社のVPNで、テザリングからでも社内ツールまで入れた
- 使うツールに、そもそもIP制限がかかっていない（情シスに確認済み）
- 会社が個人の固定IPの登録を認めていない、または私物のVPNの利用を禁止している
- 社内ツールが「会社のVPN経由」や「会社が管理する端末」であることを条件にしている
- 帰省中は業務をしない、またはオフラインでできる作業（資料作成など）に絞れる
- IP制限のあるツールを使う作業を、帰省前後の自宅勤務日にまとめられる

たとえば「1週間の帰省のうち2日だけ働く」なら、IP制限のあるツールを使う作業を帰省前後に寄せられないか、まず上長に相談してみてください。作業日を調整するだけで、追加の契約が不要になることもあります。

会社が認めていない接続方法は使わず、迷ったら情シスに相談してください。

<p class="next">固定IPの仕組みや、取引先・会社への登録依頼の文面は「<a href="freelance-kotei-ip-hitsuyou-mail-template.html">フリーランスに固定IPは必要？不要な条件とIP登録依頼メール例文</a>」にまとめています。</p>

※ここからは、当サイトが提携している広告（アフィリエイト）の紹介です。

情シスから「個人で契約した固定IPなら登録してよい」と回答があった人向けに、株式会社インターリンクの「マイIP」の仕様をまとめます。

**公式ページで確認できなかったこと**：通信ログの保存方針、返金保証、業務で使ってよいかの規約上の条件、固定IPが利用者専用かどうか、無料体験後の課金開始と解約月の料金。会社の登録条件に関わる項目は、申し込む前に問い合わせて、その回答を情シスに共有してください。

公式サイトには次の注意書きもあります。

- ネットワーク構成によっては使えない場合があり、無料体験中に確認するよう案内されている
- VPNサーバーを経由するため、実効速度が下がる場合がある
- 特定のサイトやサービスにアクセスできない国からの利用はサポート外

### 検討するときに確かめること

- **会社PCで使える接続方式か**：WireGuardは専用アプリの対象外です。どの方式を使ってよいか、設定を自分でしてよいかは情シスの指示に従ってください
- **無料体験の期間に試せるか**：出発前に、自宅回線とテザリングの両方で「VPN接続 → 社内ツールにログイン」まで試しておきます
- **解約の手順**：帰省のときだけ使うなら、退会方法と料金の扱いを申し込む前に確認しておきます

[[aff:myip|マイIPの料金・無料体験の条件を公式サイトで確認する]]

### 契約しない場合の方法

会社のVPNで使えるなら、追加で契約する必要はありません。そのほかの方法として、①IP制限のあるツールを使う作業を帰省前後の自宅勤務日に寄せる、②実家での勤務日を休暇に変える、③会社のVPNやリモート接続の利用を申請する（未申請の場合）、があります。

## 当日つながらなかったとき

準備をしても、当日つながらないことはあります。自己判断で接続設定を変えず、次の順で動きます。

**1. 自分で確かめられることだけ試す（10〜15分を目安に）**
- 会社のVPNに接続できているか（接続表示が出ているか）
- PCとルーター（またはスマホ）を再起動する
- 会社のルールで認められていれば、実家Wi-Fiとテザリングを切り替えて試す
- VPN・ツールのパスワードの有効期限が切れていないか確認する

**2. 状況を記録する**
- 発生時刻、使った回線（実家Wi-Fi／テザリング）
- エラーメッセージの画面（スクリーンショット）
- どのツールが使えて、どれが使えないか

**3. 事前に確認しておいた連絡先に連絡する**
- 情シスの休業中の緊急連絡先（チェック①で確認したもの）
- 上長への報告（業務の切り替えや休暇扱いの判断のため）

**上長への連絡例**

```
お疲れさまです。【氏名】です。
本日、帰省先から勤務を開始しましたが、【○時○分】時点で【ツール名】にログインできない状況です。
VPN接続・再起動は確認済みで、情報システム部の緊急窓口に【メール／電話】で連絡しています。
復旧までの間は、オフラインでできる【資料作成など】を進めます。
本日中に復旧しない場合の対応（作業の振り替え・休暇扱いなど）についてご相談させてください。
```

**4. つながるまでは、オフラインでできる作業に切り替える**
社内ツールを使わない作業（資料の下書き、メール文面の準備など）をあらかじめリストにしておくと、当日あわてずに済みます。

※無料のVPNやプロキシなど会社が認めていない方法、同僚や家族のアカウントの使用、許可されていないソフトの導入は避けてください。

## まとめ：出発前・前日・当日にやること

### 出発の1〜2週間前
- [ ] テレワーク規程で、帰省先での勤務・回線・私物サービスのルールを確認する
- [ ] 帰省先での勤務を申請する（申請が必要な場合）
- [ ] 情シスに確認メールを送る（IP制限の有無、VPNの使い方、個人の固定IPの登録可否、休業中の連絡先）
- [ ] テザリングで「VPN接続 → 社内ツールにログイン」まで試す
- [ ] IP制限のあるツールを使う作業を、帰省前後の自宅勤務日に寄せられないか上長と相談する

### 出発の前日
- [ ] PCのアップデートを済ませ、再起動しておく

## よくある質問

### Q1. スマホのテザリングで、会社の管理画面に入れますか？

会社の仕組みによって変わります。社内ツールにIP制限がかかっていて、会社のVPNを使わずにテザリングでつなぐ場合は、キャリア側のIPアドレスが登録されていないため入れないことが多いです。会社のVPNがあれば、VPN経由で入れることもあります。出発前にテザリングで「VPN接続 → 社内ツールにログイン」まで試しておきましょう。

### Q2. マイIPの無料体験期間中に解約すれば、料金はかかりませんか？

公式サイトでは「最大2ヶ月の無料体験あり」と案内されています（2026-11-07時点）。適用条件は公式サイトに載っていますが、課金が始まるタイミングと解約月の料金の扱いは、当サイトでは公式ページで確認できませんでした（上の「公式ページで確認できなかったこと」）。申し込む前に、公式FAQか問い合わせ窓口で聞いておくと、体験後の請求で迷いません。なお、特定商取引法に基づく表記では返品は原則不可とされています。
